# 📚 지식 파일 작성 가이드

NovelForge 페르소나에 첨부하는 지식 파일을 효율적으로 작성하는 방법입니다.

---

## 🗂️ 권장 파일 구조

Gemini Gems와 동일한 구조를 추천합니다. 번호로 우선순위를 정하세요.

| 파일명 | 용도 | 중요도 |
|--------|------|--------|
| `00_INDEX.md` | 전체 파일 목록 + 간략 설명 | ★★★ |
| `01_World_Setting.md` | 세계관, 배경, 지리, 역사, 세력 | ★★★ |
| `02_Characters.md` | 주요 캐릭터 설정표 | ★★★ |
| `03_Plot_Structure.md` | 전체 플롯, 시즌별 아크 | ★★☆ |
| `04_Episode_Template.md` | 화별 구조 템플릿 | ★★☆ |
| `05_Secrets_Schedule.md` | 떡밥/복선 공개 스케줄 | ★☆☆ |
| `06_Style_Guide.md` | 문체, 금기어, 톤앤매너 | ★★★ |
| `07_Workflow.md` | AI 작업 순서/규칙 | ★☆☆ |

> **TIP:** 모든 파일이 필요하지 않습니다. 최소 `01`, `02`, `06`만 있어도 큰 효과가 있습니다.

---

## ✍️ 파일별 작성 예시

### 00_INDEX.md
```markdown
# 작품 지식 파일 인덱스

| 번호 | 파일 | 내용 |
|------|------|------|
| 01 | World_Setting | 무림 세계관, 문파, 무공 체계 |
| 02 | Characters | 주요 등장인물 30명 |
| 03 | Plot_Structure | 10권 전체 아크 |
| 06 | Style_Guide | 무협 문체 규칙 |
```

### 01_World_Setting.md
```markdown
# 세계관 설정

## 시대 배경
- 가상의 고대 중원, 당나라 풍
- 무림은 정파/사파/마도 3세력

## 지리
- 중원 5대 문파: [이름, 위치, 특징]
- 강호 주요 도시: [이름, 특징]

## 무공 체계
- 내공: 진기 → 기경팔맥 → 선천진기 (3단계)
- 검법: 초식 20개 이내, 각 초식에 이름 부여
- 금지된 무공: 흡성대법, 화골면장 (이유: ...)

## 특수 규칙
- 절대 경지: 화경(化境) = 무공의 끝
- 무공 배울 때 반드시 부작용 묘사
```

### 02_Characters.md
```markdown
# 등장인물 설정

## 주인공: 이무현
- 나이: 18세 → 25세 (7년간 성장)
- 성격: 겉으로 냉정, 속으로 따뜻. 말수 적음
- 말투: "~인 것 같군", 존댓말 기본, 감정 격할 때만 반말
- 무공: 태극검법 → 후에 혼원검법 창시
- 약점: 왼쪽 어깨 부상 (3권에서 획득)
- 인간관계: 사부에 대한 존경, 여주에 대한 서툰 감정

## 여주인공: 소연화
- 나이: 17세
- 성격: 활발, 호기심, 정의감
- 말투: "~거든!", 반말과 존댓말 혼용
- 비밀: 마도 혈통 (5권에서 공개)

## 라이벌: 천무극
[...]
```

> **핵심:** 캐릭터 설정에 **말투 예시**와 **비밀 공개 시점**을 명시하면 AI가 일관성을 유지합니다.

### 06_Style_Guide.md
```markdown
# 문체 가이드

## 기본 톤
- 진지하고 장엄한 분위기
- 유머는 캐릭터 간 대화에서만 (지문에서 X)

## 전투 묘사
- 동작 하나당 2-3문장 (과하지 않게)
- 의성어 사용 OK: 쾅, 촤악, 칭!
- 내공 묘사 시 기(氣)의 색상과 형태 언급

## 금지 사항
- 현대어 사용 금지 (예: "멘탈", "힐링")
- 4벽 파괴 금지
- 주인공이 한 번에 모든 문제 해결 X

## 대화 규칙
- 대화는 전체 분량의 30~40%
- 독백은 이탤릭 스타일로 구분
- 경어 체계: 사제 간 존댓말, 동료 간 반말

## 장면 전환
- "***"로 구분
- 시점 변경 시 첫 문장에서 장소/인물 명시
```

## ⚡ 효율적 작성 팁

### 1. 구조화하세요
```
❌ 나쁜 예: "이무현은 18살이고 검을 쓰고 차가운 성격이다."
✅ 좋은 예:
  - 나이: 18세
  - 무기: 검 (태극검)
  - 성격: 겉 냉정 / 속 따뜻
```
→ 마크다운 리스트/표 형태가 AI 인식률이 **2배 이상** 높습니다.

### 2. 짧고 명확하게
```
❌ "주인공은 원래 산골 마을 출신으로 어린 시절 부모를 잃고..."
✅ "출신: 산골 마을. 부모: 10세 때 사망 (원인: 마도 습격)"
```
→ 서사가 아닌 **데이터 시트** 스타일로 작성하세요.

### 3. 파일당 5,000자 이하 권장
| 파일 크기 | 효율 |
|-----------|------|
| ~2,000자 | ★★★ 최고 (요약 없이도 OK) |
| ~5,000자 | ★★☆ 요약 생성 권장 |
| ~10,000자 | ★☆☆ 반드시 요약 필요 |
| 10,000자+ | ⚠️ 파일 분할 권장 |

### 4. 변하는 정보 vs 고정 정보
- **고정** (세계관, 문체 규칙) → 지식 파일에 작성
- **변하는** (현재 플롯 진행, 인간관계 변화) → 스토리바이블에 작성

### 5. 요약 생성 활용
1. 원본을 충분히 상세하게 작성
2. **✨ 전체 요약 생성** 클릭
3. AI가 500자 요약을 자동 생성
4. 챕터 생성 시에는 요약만 주입 → **토큰 90% 절약**
